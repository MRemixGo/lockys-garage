# Locky's Garage

A fun math game for kids: answer math questions to earn coins, then spend them customizing your dream muscle car in the garage — new paint, rims, spoilers, decals and more!

## Play it

The game is deployed with GitHub Pages — just open the link.

## Run it yourself

```bash
npm install
npm run dev
```

Built with React + Vite + Tailwind CSS.
